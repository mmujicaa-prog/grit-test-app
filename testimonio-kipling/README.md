## Los 4 actos (hilo del poema)

1. **Serenidad** — mantener la cabeza cuando todo arde.
2. **Equilibrio** — el Triunfo y el Desastre, los dos impostores.
3. **Resiliencia** — resistir cuando solo queda la Voluntad *(clímax)*.
4. **Integridad** — caminar con reyes sin perder el trato sencillo.
